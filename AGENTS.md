# AI Repository Guide

Before using or changing `_ljp`, any crawler Step, cache behavior, product output, or browser automation, read [the `_ljp` quick guide](docs/LJP_TOOL_GUIDE.md) in full.

Treat that guide as the primary operational contract. Do not begin source tracing unless the guide lacks the needed API, runtime behavior conflicts with it, or a problem requires diagnosis. When source inspection confirms a public behavior change, update the guide in the same change.
